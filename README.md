## 🚀 Sobre mí
Soy desarrollador de software enfocado en crear **aplicaciones modernas, mantenibles y bien estructuradas**, con experiencia en **backend**, **frontend web** y **aplicaciones móviles**.

Trabajo con **Java + Spring Boot** y **PHP + Laravel** en backend,  
y con **React, React Native, TypeScript y Android** para el desarrollo de aplicaciones móviles y web, aplicando principios de **arquitectura limpia** y **APIs REST**.

- 🌱 Aprendiendo: **Microservicios, Clean Architecture y N-Capas**
- 💡 Intereses: **Backend, Full Stack, Mobile y Arquitectura de Software**
- 🤝 Abierto a colaborar en: **Proyectos backend, frontend y mobile**
- 📍 Ubicación: **Neiva, Colombia**
- ☕ Filosofía: *Buen código antes que más código*
